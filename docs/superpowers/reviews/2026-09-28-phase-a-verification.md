1. 新初始化工程直接使用独立开发分支，不另外建 worktree。代价：后续同时开展的工作需另行隔离。
2. 可信 worker 协议增加 `event_ack`，主进程提交事件后才确认。代价：每个事件多一次进程通信。
3. 真实本地 HTTP 请求在 Retry-After 等待期间取消，代替模拟时钟。代价：测试不精确断言退避的墙钟时长。
