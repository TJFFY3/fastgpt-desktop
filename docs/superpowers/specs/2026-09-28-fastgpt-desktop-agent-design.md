# FastGPT 桌面端 Agent：需求与架构提案

日期：2026-09-28。状态：用户已确认设计；尚未实现产品代码。

## 1. 目标与已确认约束

构建可配置模型、持续对话、执行工具与 Skill，并与 FastGPT 共享身份和资源权限的桌面 Agent。

用户已确认：

- 桌面技术栈采用 Electron + React + TypeScript。
- 同时对接 FastGPT 社区版和商业版。
- 首版采用本地 Docker 沙箱执行 Agent 代码和 Skill 脚本。
- 必须覆盖模型接入、Session 管理、上下文压缩与记忆、FastGPT 工作流与 Agent 调用、SSO 与权限互通、工作区沙箱、Skill 导入导出与执行这七项功能。

本轮设计确认后采用的方案与约束：

- 桌面核心本地运行，FastGPT 作为远程身份与应用能力来源。
- 工程结构为桌面应用、独立核心包、FastGPT 适配包和沙箱适配包；如服务端没有桌面授权能力，另外交付身份桥接服务。
- 支持 macOS、Windows、Linux；当前机器可完成 macOS 实机验证，其他平台需要对应 CI/机器验证。
- 默认会话与记忆本地持久化，首版不包含跨设备同步。

尚需联调信息：实际 FastGPT 版本、实例地址、商业版授权及 API 范围、可否增加服务端接口、现有 SSO 提供方。缺少这些信息时可以推进通用核心，但不能宣称真实 SSO/权限联调通过。

## 2. 方案选择

| 方案 | 优点 | 代价和适用范围 |
| --- | --- | --- |
| 本地 Agent + FastGPT 远程能力 + 独立沙箱（推荐） | 满足自定义模型、桌面记忆与本地 Skill，同时复用 FastGPT 应用和身份 | 需要维护平台适配层，双版本身份接入可能需要服务端桥接 |
| 直接承载 FastGPT 远程 Agent | 桌面编排较少，集中管理方便 | 自定义模型、桌面上下文与本地 Skill 的范围受远端版本和接口约束 |
| 完整本地 Agent，另行同步 FastGPT | 本地能力自主性强 | 身份、权限、应用元数据易产生重复管理，同步与越权防护成本更高 |

采用第一种作为推荐设计，统一运行事件与工具调用规范，让用户在同一个会话界面中使用本地 Agent 或指定的 FastGPT 远程应用。

## 3. 进程与模块边界

```text
React 桌面界面
    │ 经过验证的业务 IPC；运行事件流
Electron 主进程 / 受控 preload
    ├── 身份状态、系统凭据存储、授权策略
    ├── SQLite：会话、运行记录、摘要、记忆、Skill 元数据
    └── Agent 编排进程（仅可信应用代码）
          ├── 模型适配器 → OpenAI 兼容模型服务
          ├── 上下文管理 → 历史、摘要、记忆检索
          ├── 工具注册表 → FastGPT 适配器 → FastGPT / 身份桥接
          └── 受控工具执行器 → Sandbox Provider → 隔离工作区
```

职责划分：

| 模块 | 负责 | 边界 |
| --- | --- | --- |
| `desktop` | 窗口、登录入口、设置、会话与执行结果 UI、业务 IPC | 界面不能直接读凭据、访问任意主机文件或创建命令进程 |
| `agent-core` | 模型调用、工具循环、取消、上下文预算、事件流 | 不依赖 Electron，便于独立测试；只执行已注册并经策略检查的工具 |
| `storage` | SQLite 迁移、事务、会话和记忆检索 | 所有记录受身份命名空间约束，不在普通数据库字段中保存原始密钥 |
| `fastgpt-adapter` | 实例配置、能力清单、应用调用、身份和错误归一化 | 社区版与商业版遵循同一上层接口，按真实能力选择实现 |
| `sandbox` | 生命周期、文件传输、受控命令、资源与网络策略 | 任意 Skill 脚本和模型生成代码只能在隔离执行环境中运行 |
| `skills` | 包验证、版本管理、导入导出、按需加载 | Skill 内容是任务材料，不能修改系统授权策略 |
| `identity-bridge`（按接入条件需要） | 浏览器授权、账号映射、桌面令牌、服务端权限检查 | 是新增后端能力，不假装是 FastGPT 已提供的标准接口 |

Electron 配置要求：`nodeIntegration: false`、`contextIsolation: true`、`sandbox: true`，限制导航和窗口创建，验证每个 IPC 的来源、参数与当前身份。使用窄业务接口，不向页面公开通用 `ipcRenderer`、文件 API 或命令执行 API。依据 [Electron 安全建议](https://www.electronjs.org/docs/latest/tutorial/security)。

Agent 编排进程只用于稳定性和职责隔离，不能当作恶意脚本的安全沙箱。

## 4. 七项功能的实现规格

### 4.1 OpenAI 协议模型接入

- 可保存多个供应商：名称、Base URL、模型 ID、密钥引用、上下文窗口、最大输出、超时和显式能力开关。
- 首版兼容基线为 Chat Completions，覆盖非流式响应、SSE 文本增量和 `tool_calls`；Responses API 作为后续适配，不作为“OpenAI 兼容”的隐含要求。
- 支持手动填写模型 ID；供应商提供模型枚举时可发现模型，枚举失败不阻塞手动配置。
- 提供连接测试和能力探测。模型不支持工具调用时允许普通聊天，并明确提示工具能力不可用。
- SSE 解析支持 UTF-8 跨块、JSON 跨块、工具参数多次增量及结束事件。参数完整且通过 schema 验证后才允许执行。
- 保存不同模型的参数支持情况；不将 `temperature`、usage、JSON schema、并行工具调用等作为每个兼容端点的必备能力。
- 网络请求支持取消、超时、限流退避；已产生副作用的工具执行不得因模型或网络重试而自动重复。
- 密钥放入操作系统安全存储；无法使用安全存储时允许仅本次运行使用，不自动降级为明文持久化。界面只显示脱敏信息。

协议依据：[OpenAI 流式响应](https://developers.openai.com/api/docs/guides/streaming-responses)、[工具调用](https://developers.openai.com/api/docs/guides/function-calling)。第三方服务仍需独立兼容性验证。

### 4.2 Session 会话管理

- 新建、重命名、搜索、置顶、归档、删除、恢复历史；重启应用后保留已持久化的消息和运行结果。
- 明确区分聊天 Session、单次 Run、工作区 Workspace 和 FastGPT 远程 chatId。
- 每个 Session 固定执行模式、身份命名空间和工作区；切换远程实例、账号、团队或应用时创建独立会话或明确选择已有会话。
- 首版每个 Session 只允许一个活动 Run；不同 Session 可以并行，避免同一会话消息顺序冲突。
- Run 状态：`queued`、`running`、`waiting_approval`、`waiting_input`、`cancelling`、`completed`、`cancelled`、`failed`、`interrupted`。
- 保存运行事件和工具结果；崩溃后未结束的 Run 标记为 interrupted，禁止自动重放有副作用的操作。
- 会话删除明确区分本地记录、远端会话、工作区产物；本地删除不会隐式删除远端数据。

命名空间包含 `instanceId + accountId + teamId`，本地离线身份单独使用 `local` 命名空间。不得通过修改 UI 查询参数读取另一身份的数据。

### 4.3 上下文压缩、短期和长期记忆

将“完整历史保存”“发送给模型的上下文”和“跨会话长期记忆”分别管理。

**短期上下文：** 系统指令、当前任务、近期完整轮次、历史摘要、当前相关记忆。完整历史留在数据库，压缩仅影响组装出的模型输入。

**预算与压缩：**

- 每个模型配置上下文窗口 `C` 和输出预留 `O`；安全余量 `S` 默认取 `max(1024, ceil(C × 0.05))`，可配置。输入预算 `B = C - O - S`，要求 B 大于零。
- 输入估算超过 B 的 80% 时尝试压缩到 B 的 60% 以下；保留系统指令、当前用户输入和完整工具调用/结果配对。
- 优先保留最近 6 个完整交互轮次；超大当前输入或单个完整轮次仍超预算时，提示缩小输入或切换模型，不截断工具协议。
- 摘要保存任务目标、用户约束、已完成步骤、关键结论、产物引用与未完成事项，并保存来源消息范围和版本。
- 先生成并保存成功的摘要，再原子更新摘要游标；失败时保留原历史。只有能够在预算内组装输入时才继续模型请求。
- 优先使用供应商对应的 tokenizer；无法精确计数时使用保守估算并在 UI 标注估算。不能宣称估算覆盖所有模型的硬限制。
- 工具输出设置有界大小，完整输出保存为附件；超限时向模型提供截断说明和受控读取引用。

**长期记忆：**

- 包含用户确认的偏好、事实和项目约定；支持查看、编辑、删除、禁用以及“记住这条”手动操作。
- 自动提取形成候选，默认经用户确认后进入长期记忆；用户可在设置中开启自动保存低风险候选。
- 记录来源、作用域、创建时间、更新时间、有效期与冲突关系；不从模型臆测中直接建立确定事实。
- 首版采用 SQLite 全文检索和显式标签，按用户/工作区作用域过滤后召回；不要求额外配置 embedding 服务才能使用记忆。
- 密钥、认证 token 和标记为敏感的材料禁止进入长期记忆。记忆内容作为低信任上下文，不能覆盖系统指令或授权决策。
- 切换账号、团队或实例后重新装配上下文，禁止继承上一身份的摘要与召回缓存。

### 4.4 FastGPT 工作流和 Agent 调用

提供两种互补使用方式：

1. **远程应用会话**：用户直接选择 FastGPT 应用，桌面负责交互和事件展示，模型与流程由远端配置决定。
2. **本地 Agent 工具**：在本地 Agent 中注册授权的 FastGPT 应用或工作流为工具，校验输入后调用远端，结果回传本地 Agent。

适配要求：

- 资源选择仅展示当前身份有权限的应用。接口不支持枚举时允许手动填写 appId，但调用时仍由服务端验证权限。
- 使用应用/工作流输入 schema 校验参数；没有 schema 时使用受限 JSON 输入和服务端错误反馈，不猜测必填变量。
- 为有状态远程调用保存 `(instanceId, accountId, teamId, appId, sessionId) → remoteChatId` 映射，不能只按 appId 复用会话。
- 有 chatId 时按远端会话协议发送当前输入；无状态调用才发送完整构造的 messages，避免本地与远端重复拼接历史。
- 文本、工具/节点进度、交互表单、最终输出、错误归一化为桌面事件；工作流等待输入时保持远程会话标识。
- 停止桌面请求只保证终止本地等待。仅在实例提供可验证取消接口时，宣称远程执行已取消；不得把断开 SSE 等同于远程副作用回滚。
- 不支持已发布 Agent 调用或某类事件时展示明确的版本/能力提示，不用模拟结果冒充真实调用。

FastGPT 文档自 4.15.0 起要求以实例的 `/apidoc/devapi` 和 `/apidoc/systemopenapi` 为准。旧说明中的 `/api/v1/chat/completions`、appId、chatId 和 variables 可作为兼容适配参考，实际协议必须针对目标实例验证。依据 [FastGPT API 文档介绍](https://doc.fastgpt.io/zh-CN/openapi/intro)、[对话接口参考](https://doc.fastgpt.io/zh-CN/openapi/chat)。

### 4.5 SSO、身份和权限互通

同一个身份体系需要同时解决登录认证、FastGPT 成员映射和每次资源调用的授权。

**共同机制：**

- 优先在系统浏览器登录，桌面通过 loopback 或已注册回调接收一次性授权码。桌面属于公开客户端，不能内置 OAuth client secret。
- 有标准 native OAuth 支持时采用授权码 + PKCE；没有时由新增身份桥接在服务端完成认证并签发桌面授权码。
- 桥接授权码绑定 PKCE challenge、state、客户端回调和浏览器已认证身份；有效期 60 秒、只能消费一次。换取短期 access token，refresh token 轮换并支持服务端撤销。
- 令牌不得放在跳转 URL 中直接传递；回调校验 scheme、host、port、path、state 和发起的登录事务。
- 身份包含实例、用户、团队、成员和可验证资源范围；请求中的 userId/teamId 只作为选择目标，不作为认证证据。
- 切换团队、登出、token 过期或服务端撤权时撤销本地活动授权，停止相关新调用，清空凭据和缓存。已经在远端产生的副作用按远端能力处理。
- 本地策略决定用户允许 Agent 执行哪些操作，FastGPT 服务端决定用户是否能访问目标资源。两项都通过才能执行。
- API Key 是调用凭据；只有服务端验证它代表的身份和范围后，才能用于权限互通。手动粘贴 Key 不能替代 SSO 验收。

**两版适配：**

| 场景 | 登录方式 | 权限依据 | 需增加的能力 |
| --- | --- | --- | --- |
| 商业版已有企业 SSO | 复用现有浏览器登录/IdP，再交换桌面凭据 | FastGPT 的团队、成员和应用授权 | 若未提供桌面授权码与令牌交换，增加桥接；验证商业版接口范围 |
| 社区版已有用户登录 | 复用 FastGPT 登录态，通过服务端交换桌面凭据 | 社区版现有成员和资源权限检查 | 增加桌面授权桥接；需要企业 SSO 时增加 IdP 接入和成员映射 |
| 仅允许 API Key 集成 | Key 验证与受限应用调用 | Key 代表的实际权限范围 | 标记为 API 连接模式；不能计入完整 SSO/身份互通交付 |

官方 SSO/成员同步文档描述的是 FastGPT-pro 与 SSO-Service 的对接，不构成社区版原生 SSO 或 FastGPT 本身作为 OAuth 提供方的证明。依据 [FastGPT SSO 文档](https://doc.fastgpt.io/zh-CN/guide/admin/sso)。

如果使用 `authProxy`，仅由可信后端根据已认证用户生成代理身份，并遵守实例对密钥和成员权限的限制；不接受桌面客户端自由指定任意成员。支持条件依据 [FastGPT API 说明](https://doc.fastgpt.io/zh-CN/openapi/intro)。没有可验证委托接口时，采用服务端原有权限检查或成员级凭据，而不是使用共享管理员 Key 直接放行。

### 4.6 沙箱和工作区隔离

执行链必须为：模型提议 → 参数验证 → 权限策略 → 必要的用户授权 → 沙箱执行 → 有界结果/产物。

- 每个身份命名空间下的 Session 分配独立执行环境和工作区。相同项目可复用明确授权的只读输入，但不能隐式共享可写卷。
- 可信桌面进程通过文件选择/导入把授权文件放入沙箱。沙箱不能读取用户主目录、凭据目录、任意宿主机路径或容器引擎 socket。
- 本地 Docker Provider 使用非 root 用户、去除 capabilities、no-new-privileges、只读根文件系统、专用可写工作卷及临时目录；禁止 privileged、host PID/IPC/network 和 devices 挂载。
- 默认网络禁用。需下载依赖等操作时，通过显式授权的受控出口代理执行，代理验证实际连接地址及重定向，阻止元数据地址和未授权内网目标。
- 开发方配置的模型和 FastGPT 内网地址可以经可信桌面/桥接层按实例配置访问，不据此开放任意 Skill 的内网访问。
- 初始资源上限：2 CPU、1 GiB 内存、128 个进程、单命令 120 秒、单次输出 1 MiB；工作区总配额 1 GiB。Provider 无法实施某项上限时必须报告限制；工作区配额需要有真实强制手段，不能只在 UI 展示数值。
- 启动前验证 Provider 和策略是否可用。沙箱不可用时禁用脚本工具，普通聊天仍可使用；不能降级到宿主机命令执行。
- 结束后停止进程并释放临时环境；保留用户选择保存的产物，清理只针对本应用有明确归属标记的资源。
- 默认产物先留在沙箱；用户显式导出到本机，覆盖已有文件时再次确认目标。

Electron 渲染沙箱与 Agent 代码执行沙箱解决不同边界，两者都需要。FastGPT OpenSandbox 官方明确说明默认没有网络隔离，复用远端沙箱时也必须增加或验证出口隔离，不能将部署成功视为安全验收。依据 [OpenSandbox 配置](https://doc.fastgpt.io/zh-CN/self-host/config/sandbox/opensandbox)、[Docker 运行参数](https://docs.docker.com/reference/cli/docker/container/run)。

首版实现用户已选择的本地 Docker Provider；远程沙箱仅保留可替换接口，不纳入首版功能验收。本地 Docker 需要用户机器提供可用的 Linux 容器运行时；应用不擅自安装该运行时。远程 Provider 则要求部署身份验证、会话隔离和文件传输服务。容器共享内核，若威胁模型要求更强隔离，需选择具备相应边界的 VM/微虚拟机服务并单独验收。

### 4.7 Skill 导入、导出、管理和调用

- 采用 Agent Skills 的 `SKILL.md` 格式，包含必需的 name/description 和可选 scripts、references、assets；允许导入目录或 ZIP，导出为保留该结构的 ZIP。
- 支持查看、启用/禁用、删除、多版本安装和会话版本固定。冲突时展示差异并由用户选择，不能静默覆盖现用版本。
- 安装记录内容 hash、版本、来源、作用域和本地授权；`allowed-tools` 或 Skill 文本是能力请求，不能给自身授权。
- 元数据常驻索引，选中后才加载正文，再按需加载引用和资源，控制上下文成本。
- 支持用户指定 Skill，也支持 Agent 根据描述选择；选择和后续工具执行进入可查看的运行记录。
- Skill 脚本只通过 Sandbox Provider 执行，纯指令 Skill 可以在无脚本沙箱时加载，但其请求的代码执行仍被阻止。
- ZIP 导入在临时区域验证后原子安装：禁止绝对路径、`..` 穿越、符号链接/硬链接、路径碰撞、大小写碰撞、设备文件和超额解压。
- 初始导入限制：压缩文件不超过 20 MiB、解压总量不超过 100 MiB、文件不超过 1000 个；每个文件实时检查，不只相信 ZIP 头声明。
- 导出只包含所选安装版本的 Skill 文件，不包含运行工作区、用户记忆、凭据和安装授权。

格式依据：[Agent Skills 规范](https://agentskills.io/specification)。版本、信任和本地授权是桌面产品管理元数据，不强迫外部 Skill 使用私有字段才能导入。

## 5. 持久化与审计

首版使用 SQLite，以迁移管理 schema。建议实体：

| 实体 | 核心字段/用途 |
| --- | --- |
| Instance / Principal | 实例、账号、团队命名空间和已验证能力 |
| Provider / Model | 非敏感配置、能力与 credentialRef |
| Session / Message | 执行模式、工作区、消息序号、内容、附件引用 |
| Run / RunEvent / ToolCall | 状态、递增事件序号、调用参数、授权决定、结果与错误 |
| Summary | 覆盖消息范围、内容版本、预算估算 |
| Memory / MemoryCandidate | 内容、作用域、来源、确认状态、有效期 |
| Skill / SkillVersion / Grant | 来源、hash、固定版本、授权范围 |
| Workspace / Artifact | 隔离资源标识、归属、文件大小与导出记录 |
| RemoteSessionBinding | 本地 Session 与远端 appId/chatId 对应关系 |

身份变化会使缓存键和数据库访问范围同步变化。日志记录操作归属、资源和状态，认证头、密钥和敏感内容脱敏。工具产物和审计记录按同样的命名空间隔离。普通 SQLite 文件不宣称具备内容加密；磁盘加密需求需单独明确。

## 6. 分阶段交付边界

这是工作拆分和验收顺序，详细实现计划在设计确认后分别编写。

| 阶段 | 可独立验收的交付 | 覆盖需求 | 依赖 |
| --- | --- | --- | --- |
| A：桌面 Agent 基础 | 安全桌面壳、模型配置、流式对话、受控工具循环、会话持久化、取消和重启恢复 | 1、2 | 技术栈已确认；用兼容测试端点验证协议 |
| B：上下文与记忆 | 预算控制、摘要压缩、记忆候选与管理、身份隔离 | 3 | A 的消息与运行事件 |
| C：沙箱与 Skill | 本地 Docker 执行环境隔离、文件导入/导出、Skill 管理与实际执行 | 6、7 | A 的授权策略；可用本地容器运行时 |
| D：FastGPT 应用适配 | 应用选择、工作流/Agent 调用、远程状态和交互事件 | 4 | A；实例版本、API schema 与测试凭据 |
| E：两版身份与权限 | 商业版 SSO 复用、社区版桥接、团队权限验证、退出和撤权 | 5，并约束 4/6/7 | 接入两版测试环境；服务端授权方式 |
| F：联合验收与发行 | 七项完整流程和隔离测试、平台打包与安装验证 | 全部 | A–E；各目标 OS 测试条件 |

身份命名空间和授权接口从阶段 A 就进入数据与工具设计。D 在 E 完成前只能声明“API 连接已验证”，不能声明“SSO 和身份权限互通已完成”。C 的脚本能力在沙箱未通过验证时不可启用。

## 7. 验收条件

| 需求 | 必须通过的验收 |
| --- | --- |
| 1：模型 | 至少一个 OpenAI 官方端点及一个第三方兼容端点完成流式文本与工具调用；手动模型、取消、401/429、超时和无工具能力提示正确；界面/日志中无原始密钥 |
| 2：Session | 重启后消息与结果可恢复；同会话顺序一致；取消不继续触发新工具；崩溃恢复不重放副作用；账号/团队/实例间记录不可串读 |
| 3：上下文与记忆 | 构造长对话触发压缩且保留关键约束、完整工具对；失败不破坏历史；超预算有明确反馈；记忆可删除/禁用且不跨身份召回 |
| 4：FastGPT | 社区版和商业版分别完成授权应用/工作流调用、流式和交互继续；有状态调用不重复历史；无权 appId 被服务端拒绝；不支持的 Agent 接口给出真实提示 |
| 5：SSO/权限 | 两版分别完成真实浏览器登录和桌面身份交换；授权码重放、伪造身份、跨团队请求、撤权、过期、退出均被正确处理；无需共享管理员凭据 |
| 6：沙箱 | 恶意脚本无法读主目录/另一会话卷/凭据；默认不能联网；授权网络不允许绕过代理；超时、进程和内存限制有效；运行时缺失不回退宿主机；产物导出不越界 |
| 7：Skill | 有效目录/ZIP 可导入、固定版本、运行和导出再导入；恶意压缩路径、链接、大小写碰撞和解压膨胀被拒绝；Skill 声明无法提升权限 |

协议和隔离测试可使用受控模拟服务，但真实模型、两版 FastGPT、SSO 与目标操作系统必须分别联调；模拟通过不能替代这些验收。
